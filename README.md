# 🐾 GitHub Trail

一个轻量的 GitHub 浏览足迹工具。安装油猴脚本后，自动记住看过的仓库与用户主页，方便搜索、收藏和再次访问。

版本：**1.2.0** · 协议：[AGPL-3.0](LICENSE)

## 安装与升级

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 `github-trail.user.js`，将完整代码粘贴到油猴脚本编辑器并保存。升级时替换原脚本内容，不要同时启用两个副本。
3. 刷新 GitHub，点击右下角 **Trail**，或按 **Alt + Shift + H** 打开面板。

已有的 1.1.0 历史、配置和 AI 会话会继续使用原存储键。升级前可以先导出一份历史备份。安装后的常规使用无需 Node.js，也无需构建。

## 查找和整理足迹

- 搜索仓库名、作者和用户名，支持空格分隔的多个关键词。
- 按仓库 / 用户、最近 7 天 / 30 天筛选；按最近访问、访问次数或名称排序。
- 用「全部足迹 / 按类型」切换视图，点击星标收藏，再用「收藏」筛选。
- 单条删除后可以撤销最近一次删除。清空全部历史在设置页，需要再次确认。
- 每页显示 30 条，可加载更多；每类最多保留最近 500 条，收藏也受此保留上限约束。
- 支持深色、浅色及跟随 GitHub / 系统。面板样式使用 Shadow DOM 隔离，避免与 GitHub 样式冲突。
- 按 Esc 关闭，Tab 在面板内切换，关闭后恢复焦点。支持窄屏和减少动态效果设置。

仓库的代码、Issue、Pull Request、Wiki 等子页面会归入同一个仓库条目，链接返回仓库首页，不保存子页面正文或独立 Issue 标题。同一次页面导航的重复 Turbo / PJAX 事件只计一次；重新访问或刷新会计为新访问。设置中可暂停记录。

## 导入、导出和同步

导出为 JSON，仅包含历史记录与收藏，不包含密码、API Key 或 AI 对话。导入采用合并方式，保留已有记录；文件上限 2 MB。会校验文件结构、重建可信的 GitHub 链接，并统一大小写键，重复导入不会重复累加访问次数。

WebDAV 是可选的**手动合并同步**：

1. 在设置中启用 WebDAV，填写已存在的 HTTPS 文件夹地址、用户名和密码并保存。
2. 返回历史页点击「立即同步」。脚本读取并合并远端 `github-history.json`，再写回。
3. 如远端提供 ETag，会使用条件写入，发生冲突时提示重新同步。

删除和清空只影响本地，手动同步或再次导入可能恢复远端记录。访问次数合并取较大值，避免重复同步翻倍；不会精确相加不同设备的离线访问次数。服务器未提供强 ETag 时，无法保证多设备同时写入不冲突。

现代浏览器通过 Web Locks 协调同一浏览器的多个 GitHub 标签页写入；缺少该 API 的浏览器仅保证当前标签页内顺序写入。

## AI 分析（可选）

填写支持 **Chat Completions** 的 HTTPS API 地址、API Key 和模型名称。高级选项可调整温度、输出风格和提示词。

点击「开始分析」时，会将最近最多 80 个仓库和 80 位用户的名称、访问时间及次数发送给你配置的服务。追问会附带会话上下文；不会读取仓库源代码。没有历史或缺少配置时不会发请求。

- 显示请求、鉴权和保存错误，失败追问保留草稿。
- Ctrl / ⌘ + Enter 发送追问。
- 保留最多 20 个本地会话，长对话保留最初上下文与最近轮次。
- 浏览历史只用于推测兴趣，不代表实际学习时长或技能水平。没有自动周报或后台分析任务。

历史、凭据和会话存储在油猴管理的本地存储中。只有主动同步、分析或追问才会发送相关数据到配置的服务；普通记录无需远端服务。

## 开发与验证

脚本是单文件、无运行时依赖。Node.js 20+：

```sh
npm run check
npm test
npm install
npm run test:browser
```

浏览器测试使用 `playwright-core` 和本机 Chrome / Edge，也可通过 `BROWSER_PATH` 指定浏览器路径。测试以拦截的 GitHub 页面和模拟 `GM_*` API 验证深浅色、样式隔离、窄屏、键盘、搜索筛选、记录管理、导入导出、设置、AI 和导航事件，不使用真实账号或密钥。截图写入 `tests/artifacts/`，已加入 Git 忽略。

真实油猴管理器、WebDAV 服务商和 AI 服务商仍需使用自己的配置做一次连通性验证。
